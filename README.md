# 🎓 Sistema de Alumnos

Trabajo práctico desarrollado para la universidad.

El proyecto consiste en un sistema para la gestión de alumnos, desarrollado con el objetivo de aplicar los conceptos y herramientas aprendidos durante la cursada.

## 📋 Descripción

La aplicación permite administrar información relacionada con los alumnos mediante una interfaz gráfica.

El proyecto busca poner en práctica conceptos de programación, manejo de datos y desarrollo de aplicaciones vistos durante la materia.

## ✨ Funcionalidades

- 👨‍🎓 Gestión de alumnos
- ➕ Alta de alumnos
- ✏️ Modificación de datos
- 🗑️ Eliminación de registros
- 🔎 Consulta de información
- 🖥️ Interfaz gráfica para interactuar con el sistema

## 🛠️ Tecnologías utilizadas

- **C#**
- **.NET**
- **Visual Studio**
